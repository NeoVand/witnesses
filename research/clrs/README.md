# CLRS-30

The looped block of OR-join and power-mean channels on the twelve CLRS-30 graph tasks without hints (Section
"What the principles predict elsewhere", Fig. 5a-c, Methods "CLRS-30", Supplementary Table "CLRS-30", CLRS rows of
the registered-outcomes table). Training ran on one NVIDIA L4 per run.

## Install and rerun

- Modal (`modal_clrs.py`), app and volume `witnesses-clrs`, Python 3.12. Data job: `dm-clrs==2.0.3`,
  `numpy==2.5.4`, CPU. Training job: `jax[cuda12]==0.8.0`, `optax==0.2.6`, `numpy==2.3.4`, one L4.
- `modal deploy modal_clrs.py`; `python spawn_clrs.py data`, then `fresh10` and `fresh13`; then
  `python spawn_clrs.py <group>` for `c1 c3 c7 c8 c9 c10 c13 c14 c15 c16 c17` (`c10eval` after c1, c3, c9).
  `spawn_clrs.py` writes `calls_<group>.json` beside itself (git-ignored).
- Fetch runs with `modal volume get witnesses-clrs clrs/runs/<id> results/`; score with `python -I score.py results c13-`
  and `FRESH_SEED=20261109 python -I score_fresh.py results c13` (needs dm-clrs and jax on CPU).
- The analyses below need only numpy (`c15_cond*.py`, `c16_kappa.py` also read the shipped c15/c16 parameters).

| `diagnose_c3.py` | `results/c13_scc_dfs_anatomy.txt`, `results/c17_scc_anatomy.txt` | SCC split (98.8-100 / 66.5-70.4), DFS by depth |

| `c15_anatomy.py` | `results/c15_anatomy_c1{3,5,6}.json` | Prim errors: 98 of 149 to own child, by depth |
| `c15_hand.py`, `c15_cond.py`, `c15_cond_rules.py`, `c16_kappa.py` | `results/c15_hand_eps0.0001.json`, `results/c15_cond_*.json`, `results/c1{5,6}_cond_rules.json`, `results/c16_kappa.json` | Kirchhoff read-outs: exact on the true tree (2,048 of 2,048), best head 1,990-2,005, learned shift 0.43 |

`results/<run>/result.json` holds the job config and per-K scores of every reported run (c1, c3, c7-c10, c13-c17).
Prediction files ship for the runs the error analyses and Fig. 5 data read (c13 dfs, Bellman-Ford, Dijkstra, Kruskal,
Prim, SCC; c14 dfs; c15/c16 Prim; c17 SCC). Not shipped: the other datasets (regenerated by `gen_data.py`), other
checkpoints and prediction dumps (about 175 MB) and training curves.
